晶途拾光 / Crystal Trail — 网页版使用说明
============================================================

【这是什么】
一个单独的 HTML 文件，里面装着一整个像素解谜游戏。不需要安装、
不需要联网、不需要服务器。所有代码和图标都内联在这一个文件里。

【怎么玩】
双击「晶途拾光.html」，用浏览器打开即可。
推荐 Chrome / Edge / Firefox / Safari 的近年版本。

  方向键 或 WASD   移动
  空格 / W / ↑     跳跃（按住跳得更高）
  E / 回车         交互、对话翻页、确认
  ↓                从薄平台上落下
  Esc              暂停 / 返回
  F11              全屏

【怎么发给别人】
· 微信 / QQ / 邮件 / 网盘直接传这一个文件就行
· 对方存到桌面，双击打开，就可以玩了
· 文件约 0.9 MB

【想做成在线链接】
把这个文件原样上传到任意静态托管即可，无需任何构建：
· GitHub Pages       仓库里放这一个文件，改名 index.html
· Netlify / Vercel   直接把文件拖进去
· 任意对象存储        设置 Content-Type: text/html
上传后任何人用浏览器打开链接就能玩。

【存档】
进度存在浏览器的 localStorage 里，和具体浏览器绑定。
换浏览器、换设备、清空浏览器数据都会丢进度。
游戏内有 3 个手动存档位 + 1 个自动存档位。

【内容】
5 个主题 × 5 关 = 25 关，60 件拾遗宝物，5 枚本源彩晶，
中英双语（设置里切换），完整故事线（图鉴最后一页）。
一局 3 条命，掉坑或撞滚石各扣 1 条。

【已知限制】
· 没有安装包，玩法就是浏览器
· 手机浏览器也能玩（会自动出触屏控件），但推荐桌面
